# Reporting an exploit

Some bugs are dangerous to post where anyone can read them: duplicating items, riding or taking another player's
mount, getting around a server's rules, or crashing a server on purpose. Please report those privately, so they can
be fixed before anyone abuses them.

**[Report it privately](https://github.com/BenDol/Fantasy-Mounts-Report/security/advisories/new)** (or open the
**Security** tab and choose **Report a vulnerability**). Only you and the developer can see it.

Include the Minecraft version, the mod loader and its version, the Fantasy Mounts version, and the steps to make it
happen. The report stays private while it is being fixed.

Everything else, ordinary bugs and crashes, goes in a normal [bug report](https://github.com/BenDol/Fantasy-Mounts-Report/issues/new/choose).
